# Counter App – Flutter & Cubit

A simple Flutter application that demonstrates state management using **Cubit** from the Flutter Bloc package.

## 📱 About the Project

The Counter App is a two-team score counter application. Users can increase the score of Team A or Team B by selecting buttons with different point values (1, 2, or 3).

Each team's score is managed independently using Cubit.

## ✨ Features

- Two independent team counters.
- Increment scores by 1, 2, or 3 points.
- Real-time UI updates using BlocBuilder.
- State management using Cubit.
- Reusable custom button widget.
- Clean and simple user interface.

## 🛠️ Technologies & Packages

- Flutter
- Dart
- flutter_bloc
- Cubit
- Material Design

## 🧠 Concepts Practiced

- Cubit state management.
- BlocProvider and BlocBuilder.
- Creating and emitting custom states.
- Separating UI from business logic.
- Reusable widgets.
- Passing parameters between widgets.

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/D-Douaa/Counter.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Counter
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```
